# Azure Solutions Architect Expert Notes (AZ-305) & Multi-Cloud Strategy

As professionals expanding from Google Cloud Professional Cloud Architect into the Microsoft ecosystem, designing resilient, secure, and scalable enterprise solutions requires aligning Azure Well-Architected Framework principles with multi-cloud governance.

## Core Architecture Domains

1. **Identity and Governance:** Implementing Azure Active Directory (Microsoft Entra ID), role-based access control (RBAC), and multi-subscription management hierarchies.
2. **Data Storage Solutions:** Selecting appropriate storage tiers, SQL database scaling options, and geo-replication strategies.
3. **Business Continuity:** Designing disaster recovery, backup schedules, and high-availability topologies.
